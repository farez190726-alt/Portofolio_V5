Light Mode & Dark Mode

Menggunakan palet warna Slate 50/100, border halus, dan typography kontras tinggi untuk Light Mode. Dark Mode menggunakan palet Midnight Indigo (#0C101D) dengan aksen Neon Cyan (#00F0FF) sesuai Figma.

Komponen UI 100% Identik

Mencakup Donut Gauge Saldo, Transaction History (Gopay, Dana, Tokopedia, ShopeePay), Stacked Credit Cards, 4 Quick Actions, dan SVG Area Wave Chart dengan Period Filter (Week, Month, Year).

Integrasi React & Tailwind

Kode komponen React lengkap juga telah ditambahkan ke dalam project src/Pages/WalletApp.jsx dan dapat diakses melalui route /wallet.
